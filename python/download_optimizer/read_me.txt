This is a basic command script that uses Shell in order to manipulate autotuninglevel depending on whether you're gaming or downloading large files. I've used AI for this project specifically. 
In short, it checks the download sizes (minus the ones in the exceptions) and sets the autotuninglevel to either "normal" or "disabled". Disabled is typically best for gaming when you don't have the best router (like the ones that have an SQM) and your CPU is relatively modern (like a Ryzen 7) since it'll stop Windows from saturating the bandwidth and cause jitter (you can check this in a Waveform test) at the cost of heavily dropping your download speeds, which aren't super necessary when you're gaming unless you're getting less than 25mbps. 
To run this, run the .py file as admin.
